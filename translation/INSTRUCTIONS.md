# Translation Instructions

Mỗi agent chỉ cần đọc:

1. `translation/RULE.md`
2. `README_EN.md` của bài được giao

Sau đó dịch **nguyên page** sang `vi/.../README.md`, đọc lại nhanh một lượt và kết thúc.

Không cần đọc thêm `PROJECT_RULES.md`, `GLOSSARY.md`, prompt review, state, report hoặc audit files trừ khi task đặc biệt yêu cầu.

Không chạy prettier/check scripts cho từng page mặc định. Validation để orchestrator/CI chạy theo batch.
