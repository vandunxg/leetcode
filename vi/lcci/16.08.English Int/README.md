<pre>

<strong>Đầu vào:</strong> 123

<strong>Đầu ra:</strong> &quot;One Hundred Twenty Three&quot;

</pre>

<pre>

<pre>

<strong>Đầu vào:</strong> 1234567

<strong>Đầu ra:</strong> &quot;One Million Two Hundred Thirty Four Thousand Five Hundred Sixty Seven&quot;</pre>
