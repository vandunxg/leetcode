# [270. Closest Binary Search Tree Value 🔒](https://leetcode.com/problems/closest-binary-search-tree-value)

[中文文档](/solution/0200-0299/0270.Closest%20Binary%20Search%20Tree%20Value/README.md)

## Mô tả

<!-- description:start -->

<p>Cho <code>root</code> của một cây tìm kiếm nhị phân và giá trị <code>target</code>, hãy trả về <em>giá trị trong BST gần với</em> <code>target</code> nhất. Nếu có nhiều đáp án, hãy trả về giá trị nhỏ nhất.</p>

<pre>

<pre>

<ul>

	<li><code>-10<sup>9</sup> &lt;= target &lt;= 10<sup>9</sup></code></li>
</ul>

## Lời giải

<!-- solution:start -->

### Lời giải 1: Đệ quy

<!-- thinking:start -->

> **Tư duy**
>
> Không cần duyệt toàn bộ BST: sau khi so sánh với $target$, chỉ một cây con có thể chứa giá trị gần hơn. Trên đường đi, ta giữ lại giá trị gần nhất; nếu khoảng cách bằng nhau thì chọn giá trị nhỏ hơn.
>
> Đệ quy tiếp tục theo cây con trái hoặc phải tương ứng.

<!-- thinking:end -->

Ta định nghĩa hàm đệ quy `dfs(node)`, bắt đầu từ node hiện tại `node` để tìm node có giá trị gần với `target` nhất. Ta cập nhật đáp án bằng cách so sánh độ chênh lệch tuyệt đối giữa giá trị của node hiện tại và . Nếu target nhỏ hơn giá trị của node hiện tại, ta đệ quy tìm trong cây con trái; ngược lại, ta tìm trong cây con phải.

Độ phức tạp thời gian là $O(n)$ và độ phức tạp không gian là $O(n)$, trong đó $n$ là số node trong cây tìm kiếm nhị phân.

<!-- tabs:start -->

#### Python3

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def closestValue(self, root: Optional[TreeNode], target: float) -> int:
        def dfs(node: Optional[TreeNode]):
            if node is None:
                return
            nxt = abs(target - node.val)
            nonlocal ans, diff
            if nxt < diff or (nxt == diff and node.val < ans):
                diff = nxt
                ans = node.val
            node = node.left if target < node.val else node.right
            dfs(node)

        ans = 0
        diff = inf
        dfs(root)
        return ans
```

#### Java

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    private int ans;
    private double target;
    private double diff = Double.MAX_VALUE;

    public int closestValue(TreeNode root, double target) {
        this.target = target;
        dfs(root);
        return ans;
    }

    private void dfs(TreeNode node) {
        if (node == null) {
            return;
        }
        double nxt = Math.abs(node.val - target);
        if (nxt < diff || (nxt == diff && node.val < ans)) {
            diff = nxt;
            ans = node.val;
        }
        node = target < node.val ? node.left : node.right;
        dfs(node);
    }
}
```

func closestValue(root *TreeNode, target float64) int {
	ans := root.Val
	diff := math.MaxFloat64
	var dfs func(*TreeNode)
	dfs = func(node *TreeNode) {
		if node == nil {
			return
		}

			diff = nxt
			ans = node.Val
		}
		if target < float64(node.Val) {
			dfs(node.Left)
		} else {
			dfs(node.Right)
		}
	}
	dfs(root)
	return ans
}

### Lời giải 2: Lặp

<!-- thinking:start -->

> **Tư duy**
>
> Có thể thực hiện cùng cách duyệt bằng vòng lặp mà không cần call stack.

<!-- thinking:end -->

Ta có thể chuyển hàm đệ quy sang dạng lặp và dùng vòng lặp để mô phỏng quá trình đệ quy. Bắt đầu từ root, ta kiểm tra độ chênh lệch tuyệt đối giữa giá trị của node hiện tại và target có nhỏ hơn khoảng cách nhỏ nhất hiện tại hay không. Nếu có, ta cập nhật đáp án. Sau đó, dựa vào quan hệ lớn nhỏ giữa target và giá trị của node hiện tại, ta chuyển sang cây con trái hoặc phải. Vòng lặp kết thúc khi gặp node null.

Độ phức tạp thời gian là $O(n)$, trong đó $n$ là số node trong cây tìm kiếm nhị phân. Độ phức tạp không gian là $O(1)$.

<!-- tabs:start -->

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):

#         self.left = left
#         self.right = right
class Solution:
    def closestValue(self, root: Optional[TreeNode], target: float) -> int:
        ans, diff = root.val, inf
        while root:
            nxt = abs(root.val - target)
            if nxt < diff or (nxt == diff and root.val < ans):
                diff = nxt
                ans = root.val
            root = root.left if target < root.val else root.right
        return ans
```
