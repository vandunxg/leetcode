# [3248. Snake in Matrix](https://leetcode.com/problems/snake-in-matrix)

[中文文档](/solution/3200-3299/3248.Snake%20in%20Matrix/README.md)

## Mô tả

<!-- description:start -->

<p>Có một con rắn trong ma trận <code>n x n</code> <code>grid</code> và nó có thể di chuyển theo <strong>bốn hướng</strong>. Mỗi ô trong <code>grid</code> được xác định bởi vị trí: <code>grid[i][j] = (i * n) + j</code>.</p>

<p>Con rắn bắt đầu ở ô 0 và di chuyển theo một dãy lệnh.</p>

<p>Bạn được cho một số nguyên <code>n</code> biểu thị kích thước của <code>grid</code> và một mảng chuỗi <code>commands</code>, trong đó mỗi <code>command[i]</code> là một trong các giá trị <code>&quot;UP&quot;</code>, <code>&quot;RIGHT&quot;</code>, <code>&quot;DOWN&quot;</code> hoặc <code>&quot;LEFT&quot;</code>. Đảm bảo rằng con rắn luôn nằm trong ranh giới của <code>grid</code> trong suốt quá trình di chuyển.</p>

<p>Trả về vị trí của ô cuối cùng mà con rắn dừng lại sau khi thực hiện <code>commands</code>.</p>

> **Tư duy**
>
> Một con rắn di chuyển trên lưới $n\times n$ theo các lệnh và không bao giờ ra ngoài bàn cờ. Vì $n\le 10$ và có nhiều nhất $100$ lệnh, ta chỉ cần mô phỏng trực tiếp.
>
> Duy trì $(x,y)$, cập nhật hàng hoặc cột dựa trên chữ cái đầu tiên của mỗi lệnh, rồi trả về $x\times n+y$. Không cần cấp phát bàn cờ.

<!-- thinking:end -->

Ta có thể dùng hai biến $x$ và $y$ để biểu diễn vị trí của con rắn. Ban đầu, $x = y = 0$. Sau đó, duyệt qua $\textit{commands}$ và cập nhật giá trị của $x$ và $y$ dựa trên lệnh hiện tại. Cuối cùng, trả về $x \times n + y$.

Độ phức tạp thời gian là $O(n)$, trong đó $n$ là độ dài của mảng $\textit{commands}$. Độ phức tạp không gian là $O(1)$.

#### Python3

```python
class Solution:
    def finalPositionOfSnake(self, n: int, commands: List[str]) -> int:
        x = y = 0
        for c in commands:
            match c[0]:
                case "U":
                    x -= 1
                case "D":
                    x += 1
                case "L":
                    y -= 1
                case "R":
                    y += 1
        return x * n + y
```

#### Java

```java
class Solution {
    public int finalPositionOfSnake(int n, List<String> commands) {
        int x = 0, y = 0;
        for (var c : commands) {
            switch (c.charAt(0)) {
                case 'U' -> x--;
                case 'D' -> x++;
                case 'L' -> y--;
                case 'R' -> y++;
            }
        }
        return x * n + y;
    }
}
```
